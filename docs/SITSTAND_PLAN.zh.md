# 不借头支撑的坐站：实施计划

目标是按命令完成站→坐→站，头壳、下巴和颈部全过程不触地，且使用本机运行时的确定性动作。
官方基础任务允许过渡头部支撑，我们的目标比它更严格；照搬官方超参数不能保证这个目标。

## 当前决策

Q4→lowstd 不是两次独立从零。后续加大碰头惩罚、从零训练和局部反向课程小试均未产生合格候选。
最新1024×200小试仍在切换指令前失稳。保留其结果，不再沿同一配置追加长训。
本计划先运行物理前检；未通过不得跳到4096环境正式训练。

| 阶段 | 实施内容 | 放行条件 |
|---|---|---|
| P0 物理 | 当前HD1910质量/BAM下，HOME和SIT固定控制；名义、关节扰动、躯干倾角扰动；每次3秒 | 全程无头颈接触，稳定段倾角≤15°、角速度≤0.5rad/s、垂速≤0.02m/s；测得实际高度 |
| P1 目标/奖励 | 按P0修正目标或控制假设；验证支撑转换可行性，检查实际reward贡献 | 排除“不动”和“躺倒/借头”套利；配置符号/门控测试通过；未证实时明确未知 |
| P2 烟雾 | 独立任务名和新run；64环境×5轮；从零；观测/导出验证 | NaN-free，61维，奖励可算，ONNX与actor误差≤1e-3 |
| P3 学动作 | 先单方向局部初始化；1024×200诊断上限；初始探索std候选0.3（需小试验证） | 确定性切换确有进展、头颈无接触；不把本来就在终点当成功 |
| P4 扩展 | 小试达标再4096环境；每200轮复核；最大预算先1000轮；增加课程按能力 | 双向完成率与安全同时提升；下降就停止扩展，不按轮数盲目加难 |
| P5 候选 | 独立留出种子、正常速度完整视频、异常慢放、walk切入及返回 | 自动检查通过且用户视频核验后才考虑上机；训练队列不自动部署 |

P0阈值是预先声明的诊断阈值，不是官方给定的硬件安全极限。静态控制失败可能需要控制偏置或反馈策略，
不能据此推断机器人绝对无法坐稳。P0通过也不能证明全程动作可行。

初态、质量/惯量、BAM参数、实际运行限位/低通/量化只逐项改变并保留对照。
不默认把旧3498权重作为新安全任务起点；若使用其他专家，明确 warm start 与归一化兼容性。
奖励正则在动作形成后渐增；接触失败门禁始终存在，不能因探索阶段而放宽验收。
反向课程的邻近初态必须经过P0类稳定/接触检查；随机线性插值与FK抬高不是动力学可行证明。

## 可执行前检

```bash
python scripts/sim2sim_assets.py --out-dir logs/physics-assets
python scripts/pose_preflight.py --assets logs/physics-assets --out-dir logs/pose-preflight --video
```

输出含几何/舵机/输入hash、逐个初态结果和视频。失败退出码1、缺项/异常退出码2；失败时不启动训练。
视频只是固定姿态物理诊断，不是模型站→坐→站的验收视频。

加入本机实际控制处理（校准文件留在仓库外）：

```bash
python scripts/pose_preflight.py --assets logs/physics-assets --out-dir logs/pose-runtime \
    --calibration /path/to/device-calibration.toml --video
# 仅用于探查动力学可行性；不是训练轨迹，也不运行学习模型。
python scripts/pose_preflight.py --assets logs/physics-assets --out-dir logs/blend-cycle \
    --calibration /path/to/device-calibration.toml --video --cycle
# 验证实际模型，自动生成完整站→坐→站视频与异常慢放。
python scripts/sitstand_check.py --assets logs/physics-assets --onnx /path/to/policy.onnx \
    --calibration /path/to/device-calibration.toml --out-dir logs/sitstand-review
```
